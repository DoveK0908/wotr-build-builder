# 预置构筑的来源与解析说明

## 来源

`web/public/data/presets.json` 里的 24 套构筑来自社区中文 BD 合集：

- 仓库：<https://github.com/ZJUZBW/-Wotr-BD->（《开拓者-正义之怒的剧情队友的强力Build收集》）
- 作者：**aaathl**（仓库署名 ZJUZBW），版本更新页面 <https://www.aaathl.top>
- 许可：**MIT License, Copyright (c) 2023 ZJUZBW**（见该仓库的 `LICENSE`）

本项目只提取了 `README.md` 中的**文字攻略**（职业配比、专长、神话专长、属性加点、技能加点），没有收录仓库里的图片、HTML 备份与表格文件。文字内容的著作权归原作者，若原作者希望调整或移除收录，删除 `pipeline/import_presets.py` 后重跑管线即可（预置不是规划器的必需数据）。

## 抓了什么

合集里每个 `### 标题` 是一套构筑，标题本身写的就是职业配比（例如 `### 14圣武士1传统武僧1受诅巫师3突变斗士1原怒者`），正文代码块里是逐级的专长清单：

```
--通用加点1--------
1圣武士：闪避、盾牌专攻（自带）
3传统武僧：精通先攻、鹤形拳
5圣武士：包抄
**升级属性加点**：5魅力
**神话专长和能力：**
- 1屹立不倒、2神话盔甲专攻（中甲耐受）、3常备不怠……
```

导入器只取每个代码块里的**第一套加点变体**（`--变体名--------` 之后的第二套会被跳过），并跳过 `~~删除线~~` 的过期内容和「旧版本」章节。

## 怎么解析的

- **职业配比**：用游戏自己的中文职业名/变体名做**最长前缀匹配**（游标式扫描），所以 `博学士新`、`奥法暴徒新加点`、`突变斗士`、`原怒者` 这类变体写法也能认出来，并归到它的主职业。`可变兼职`/`自选` 这种「留给玩家自己填」的槽位只计数、不猜职业。
- **专长**：先按括号深度切分顿号/逗号，再去掉攻略里的语气和修饰，然后拿游戏数据里的中文名做精确匹配（专长 → 神话专长 → 法术 的顺序）。参数写在括号里（`超魔（法术甄选）`、`技能专攻（世界）`），会一并带进构筑。
- **落位**：只有当某个专长在那一级的候选槽位里**唯一可能**时才会自动填进去，避免瞎猜；填不进去的留在「待确认清单」里由你自己决定。
- **属性加点**：`**升级属性加点**：5魅力` 会映射到 4/8/12/16/20 级里第一个空着的加值位。
- **神话**：`1屹立不倒、2神话盔甲专攻（中甲耐受）` 按序号落到对应神话等级。

## 准确度（最后一次导入的实测）

| 指标 | 数值 |
| --- | --- |
| 构筑 | 24 套（14 名队友） |
| 专长/神话条目 | 278 条 |
| 认出并落到数据里的 | 238 条（85%） |
| 自动落到槽位的 | 87 个 |
| 配比里有认不出的词 | 1 套（兰恩的「可变兼职」槽） |
| 没认出来的名字 | 35 个（多为攻略正文、武器名、`自选`） |

## 已知限制

- 「可变兼职」「自选」这类槽位没有具体职业，所以有 3 套构筑只铺到 17–19 级（其余等级留给玩家自己选）。
- 攻略里偶尔会写「这条专长的具体取舍看情况」之类的整句话，会被识别成说明放进「待确认清单」，不会硬塞成专长。
- 攻略的加点顺序（先点哪个）没有被完整保留，属性 +1 一律落在 4/8/12/16/20 级。
- 攻略里写的法术选择会尽量落到对应法术，但同一个法术在多个职业法术表里都有的情况下不强行指定。

## 重新生成

```powershell
# 需要先把合集克隆下来（或指定本地的 README.md 路径）
git clone --depth 1 https://github.com/ZJUZBW/-Wotr-BD- D:\DSH\temp\Wotr-BD-

python pipeline\import_presets.py --src D:\DSH\temp\Wotr-BD-\README.md --out web\public\data
```

导入器默认读取 `D:\DSH\temp\Wotr-BD-\README.md`，也可以随时换成本地更新的攻略版本。
