## 阅读约定

- **顶部件牌条**：横向排列的牌匾，每块 = 图标 + 下方一行中文小标签；已配置的牌匾在右侧长出一小块显示所选值（图标/文字），未配置显示「＋」。最左/最右各有一个 `‹` / `›` 箭头（牌匾过多时翻页）。
- **创建/升级书页**：顶部牌匾条；左侧列表栏（搜索框 + 行）；中间详情栏；右侧「职业成长」预览栏；底部 `« ‹ 返回 | 下一项 › »` + 右下上下文按钮（`详情` / `职业成长` / `法术书` / `完成`）。
- **游戏内（角色）页**：顶部一级页签 `物品栏 角色 神话道途 法术书 日志 百科全书 地图`（当前页紫色高亮）+ 二级紫色牌匾页签 `概要 能力 武艺 职业 个人传记`；左侧固定角色栏；中间内容区。
- **游戏内左侧固定角色栏（下文简称「左栏」）**：`经验` 进度条 + `等级 N` + `数字/数字`（如 360000/2000）+ 黄色菱形加号按钮；种族头像框（含红心 `9/6` 生命/暂伤）；`中立善良` 阵营文字；`狐妖` 种族名（带性别符号）；六项属性 `STR/DEX/CON/INT/WIS/CHA` 左值右加值；`① 短刃宗师` 职业行；`攻击（近战）` 盒（武器图标 + `攻击 +5` + `伤害 1-4 / 1d4` + `重击 ×3 / 20`）；`防御等级和豁免检定` 盒（`防御等级 18 / 措手不及 13 / 接触 15 / 强韧 +0 / 反射 +7 / 意志 +0`）；`速度 30`；最底部金色饰条上的 6 个快捷槽 + 角色小头像（第 1 槽选中）。
